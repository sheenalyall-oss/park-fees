Cloud Sync — Shared History Across Your Team

How it works: A free Google Apps Script backend (running on your Google account) stores every saved voucher in a Google Sheet. All team members with this URL and the same "Sync Key" will see the same history live. No servers, no monthly fees — just your Google account.

Setup takes ~5 minutes — follow the CLOUD_SYNC_SETUP.md guide included in the package. Once set up, paste the Web App URL below and click Test Connection.

Quick Setup Steps

  1. Open script.google.com — sign in with the Google account that will "own" the shared history
  2. Click New project → paste the contents of cloud_backend.gs (from the deployment package) into Code.gs
  3. Click Deploy → New deployment → Web app → set Execute as: Me and Who has access: Anyone → click Deploy
  4. Copy the Web app URL (ends with /exec) — paste it above ↑
  5. Pick a shared Sync Key — share the URL + key with Vincent, Ops team, whoever needs access
  6. Click Save Settings, then Test Connection — green tick means you're done
Full step-by-step with screenshots in CLOUD_SYNC_SETUP.md.
